# 2026-09-12 项目审核与修复

审核基线：2576a97。范围覆盖传输与重试、历史文件存储、消息阅读位置、HTTP/WebSocket 输入、账号状态、静态预览和发布前验证。

## 已修复的问题

| 范围 | 已确认的问题 | 修复及回归证据 |
| --- | --- | --- |
| 文件保留 | 清理器会误删文件名包含 .part 的正式文件 | 仅匹配临时文件后缀，排除已登记文件及活动上传；覆盖 .part、.part-abc、.part1.zip |
| 历史隔离 | 复用其他房间或发送者的编号会返回原记录；分片可混用 | 校验记录归属，冲突返回 409；临时文件使用发送者和文件属性标识 |
| 文件一致性 | 流式上传与分片上传没有共用锁；名称清洗会导致路径碰撞 | 所有上传模式共用每编号的锁；新文件路径使用哈希区分原始编号；覆盖并发、断连和路径碰撞 |
| 传输恢复 | 点击重试只变更状态；等待期间断线不会及时结束；发送异常留下等待器 | 重试启动发送；统一管理确认、取消、断线与超时，并清理监听器和定时器 |
| 多接收方 | 组合卡片可能对已经完成的主传输执行重试；显示进度未使用组合值 | 只重试失败接收方；卡片使用组合进度 |
| 对端输入 | 数据通道仅强制类型转换；确认及取消消息未绑定来源会话 | 校验消息形状、分片长度与续传位置；校验操作归属；拒绝异常 RTC 信令 |
| 消息列表 | 最新一页刷新会覆盖已加载旧记录；每次快照重复拉取同一页 | 保留更早记录和游标，同房间请求去重；重复相同快照不再重复请求 |
| 阅读位置 | 到达显示数量上限后，新消息会移除窗口顶部内容；历史加载存在跳动 | 上翻时保留当前窗口，基于实际消息位置在绘制前恢复；组件测试覆盖消息到达、进度更新和历史插入 |
| HTTP | 畸形百分号路径可在路由解码时抛出；无效页大小可能返回全部历史 | 路由前校验 URL，返回 400；非法分页值回退到配置上限；校验历史 JSON 字段 |
| 下载 | HTML 使用 .pdf 文件名时可被内联响应 | 内联时限定 PDF 类型；HTML/SVG 强制附件响应，并设置 nosniff |
| 账号 | 迟到的会话读取可能覆盖登录/退出状态；退出失败仍清空本地账号 | 对账号操作进行版本校验，退出失败保留状态并显示错误；使用模拟响应验证竞态 |
| 静态预览 | 非法 URL、文件读取失败会成为未处理异常；不存在的 JS 返回 HTML | 返回 400/404，限制文件路径范围，处理流错误，补齐 mjs/wasm/font 等响应类型 |

分片追加写入同时改为异步文件操作，保留串行锁，减少磁盘写入对信令事件循环的阻塞。README 已同步 90 天保留和当前路由、运行环境说明。

## 验证

- npm run test:full：55 个测试文件、279 项测试通过；类型检查、ESLint、前端静态构建、服务端编译和独立服务端验收通过。
- npm run audit:prod：前后端生产依赖均报告 0 个已知漏洞。
- scripts/smoke-server.mjs：复制编译结果到独立临时目录运行，不加载真实 .env 或数据；用实际 HTTP 和 WebSocket 请求验证异常输入、身份保持、文本校验、发送者隔离、上传、范围下载、下载响应头和分页上限。
- 该服务端验收已经接入 CI 与生产部署前验证。
- 本地两个独立来源的浏览器客户端完成消息收发；阅读历史时，新消息到达前后 scrollTop 均为 2196；回到底部后自动跟随恢复；两端控制台未发现错误或警告。
- 静态预览实测：非法 URL 返回 400，缺失脚本和越界路径返回 404，随后首页仍返回 200。

## 兼容性与验证边界

- 已保存文件继续根据已有元数据中的 storagePath 读取，无需迁移文件。
- 新格式只用于后续上传；旧版本未完成的上传在新版本重试时可能从头开始，旧临时分片仍按闲置清理规则处理。
- 头像和普通文件没有新增产品大小限制；测试确认大文件元数据仍然被接受，容量配置为 0 的上传路径仍可工作。
- 现有头像、聊天气泡外观以及气泡自适应宽度未修改。
- 账号竞态使用模拟服务响应验证；没有执行真实付费生图、外部 AI 请求或 Supabase 账号写入。本报告中的本地验收不代表这些外部服务已配置或可用。
