# DD直连 全系统 UI/UX 升维与极简 Studio IDE 规范文档

---

## 📌 概述

本文档记录了 **DD直连** 按照 Apple、Linear、Raycast 与 VS Code 现代设计美学标准，对全系统各级交互界面（大厅、会话列表、消息流、多彩文件传输卡、OCR 文字识别工坊、命令行沙箱 Studio IDE）进行的深度重构、冗余精简与升维规范。

---

## 🧹 极简精简与彻底去文字冗余原则 (Radical Pruning)

1. **彻底移除多余副标题与说明段落**：
   - 命令行顶栏仅保留纯净标题 **「命令行」**，去除了多余的环境说明与标签，直接露出核心工具流。
   - 下拉弹窗去除了顶部“选择执行环境”提示语与选项下方的冗余副文本，仅保留高辨识度徽标与语言名称（`Python` / `Java` / `C` / `PlantUML`）。
   - Tab 标签去除了多余的“渲染预览”和“控制台输出”等长词，精炼为直观的 **`main.py`**、**`预览`**、**`终端`**。
## 📱 移动端自适应重构 (Mobile Responsiveness Overhaul)

1. **彻底解决左侧 Rail 与底部 Bar 双导航冲突**：
   - 在移动端（屏幕宽度 $\le$ 768px）通过全样式级覆盖隐藏桌面端侧边栏 `.dd-snaplink__rail`，全面切换为底部固定导航栏（`消息` / `设备` / `传输` / `我的`）。
2. **全屏内容自适应与消除空白压顶**：
   - 移动端解除桌面端 `64px 1fr` 与固定 `280px` 分栏网格，会话列表与设备列表铺满 100% 屏幕宽度。
   - 页面顶部无缝贴合屏幕，消除原有的大块空白塌陷。
3. **独立工坊全链路返回导航 (Back Navigation)**：
   - 修复移动端从「我的」$\rightarrow$「工具与扩展工坊」进入「命令行沙箱 (`/web-command`)」、「AI 智能助手 (`/ai-chat`)」、「图片工坊 (`/image`)」时无返回键的问题，新增自适应 `‹ 返回` 统一顶栏返回入口。
   - 修复房间对话详情页顶栏返回键被浮动层遮挡/偏移问题，将 `‹` 返回按钮无缝内嵌至房间左侧标题区（`RoomHeader`），点击可平滑退回会话列表。
4. **对话房间与空状态极简去冗 (Chat Flow & Empty State)**：
   - 移除空状态卡片底部冗长繁杂的“技术信息”说明文字，精简核心操作为「发消息」与「发送文件」，界面干脆明了。
   - 修复浅色模式下对话房间连接胶囊在移动端的文本换行和溢出问题，小屏自动隐藏多余次要信息，保持顶栏清爽居中。
   - 彻底修复房间顶栏历史遗留的 `max-height: 64px` 与 `grid` 挤压问题，保证标题、状态点与直连胶囊拥有完整独立高度，不再发生文字上下重叠。
5. **输入框内置 Emoji 表情按钮极简重构**：
   - 修复输入框内表情按钮被错误套用独立边框和白底卡片导致溢出输入框右侧边缘的视觉 BUG。
   - 表情按钮重构为无边框透明极简图标，悬停/聚焦呈现微底色反馈，与输入框融为一体。
6. **传输面板与暗黑模式适配**：
   - 修复传输列表与空状态卡片在暗黑模式下的反色白底问题，统一为 `#18181b` 纯粹暗色质感与翡翠操作按钮。
7. **独立扩展工坊与沙箱移动端适配**：
   - 修复了 `/web-command`（命令行沙箱）和 `/image`（图片工坊）在移动端被挤压成 64px 细条的网格冲突问题，全面切换为 100% 满屏流式排版。
   - 优化了 OCR 文字提取弹窗在移动端以原生 Bottom Sheet 模态展示，配合全屏暗色遮罩与自适应文本操作区。

## 🎨 核心重塑与设计体系

### 1. 🗂️ 搜索栏与会话列表 (Sidebar & Conversation List)
- **搜索框快捷微徽标**：内置 `⌘K` 快捷键小胶囊，聚焦时激发翡翠环形微光投影（`box-shadow: 0 0 0 3px rgba(16, 185, 129, 0.14)`），支持一键清空。
- **左侧翡翠发光指示条**：当前选中的会话左边缘展示专属纵向发光条（`width: 3.5px; background: #10b981; box-shadow: 0 0 8px rgba(16, 185, 129, 0.6)`），悬停带有微升浮动质感（`translateY(-1px)`）。

### 2. 🚀 大厅迎宾工作舱 (Lobby Hero Hub)
- **多层呼吸光晕头像 (Pulsing Avatar Beacon)**：中央头像配备 `@keyframes pulseAura` 呼吸波纹动效，强化等待连接与直连就绪的视觉感知。
- **3D 悬浮动作矩阵**：
  - 「发消息」主按钮：高对比翡翠绿发光胶囊（`box-shadow: 0 4px 12px rgba(16, 185, 129, 0.3)`）。
  - 「发送文件」、「设备列表」：亚光微质感副胶囊。
  - 卡片容器：大曲率圆角（`24px`）与 `0 20px 48px` 柔和悬浮层深投影。

### 3. 💬 消息流与多彩文件传输卡 (Message Stream & File Cards)
- **己方消息气泡**：升级为**翡翠微渐变**（`linear-gradient(135deg, #10b981 0%, #059669 100%)`）搭配柔和散射阴影（`0 4px 14px rgba(16, 185, 129, 0.22)`）。
- **对方消息气泡**：高对比度纯净卡片，边框与底色自适应深浅模式。
- **多彩文件类型徽标**：
  - 📄 文档/PDF：**玫瑰红微渐变** (`#f43f5e`)
  - 🖼️ 图片/媒体：**紫罗兰微渐变** (`#8b5cf6`)
  - 📦 压缩包/安装包：**琥珀橙微渐变** (`#f59e0b`)
  - 💻 代码/文本：**翡翠绿微渐变** (`#10b981`)
  - 🎵 音频/视频：**青蓝/靛蓝微渐变** (`#06b6d4` / `#6366f1`)
- **流动条纹传输进度条**：传输进行中呈现流动条纹动态光影（`stripeProgress`）。

## ⚡ 命令行沙箱 Studio IDE 重构 (`/web-command`)

### 1. 极简顶部工具栏 (Minimal Studio Header)
- **分层解耦**：上层为独立微胶囊环境标签，下层为主标题与说明，彻底解决文字层叠与拥挤。
- **Linear / Raycast 级环境切换下拉框**：
  - 无缝整体卡片式 Popover 浮层。
  - 语言微徽标：`PY`（翡翠绿）、`JA`（琥珀橙）、`C`（科技蓝）、`UML`（紫罗兰）。
  - 左对齐排版：加粗主标题 + 微缩环境说明。
  - 右侧极简翡翠对勾 `<Check size={16} />`。
- **高阶操作按钮组**：
  - 主运行按钮：带发光微投影的 **`▶ 运行`** 按钮（运行状态自适应旋转加载动效）。
  - 定制语言下拉菜单：自适应浮层层级（`z-index: 120`）。

### 2. 双栏 Studio IDE 工作台 (Dual-Pane Studio Workspace)
- **左侧：专业代码编辑器 (Code Editor Pane)**：
  - IDE Tab 头部：配有文件图标 `<FileCode2 />` + 真实文件名（`main.py / Main.java / main.c / diagram.puml`）+ 行数与字符数微标（`2 行 · 52 字符`）。
  - 快捷操作：内置一键「清空」与「复制代码」微按钮。
  - 代码画布：专业 `JetBrains Mono` 等宽字体，行高舒展至 `1.7`，支持 Tab 缩进。
- **右侧：终端控制台与渲染器 (Terminal Console / Viewer Pane)**：
  - Terminal Tab 头部：配有 `<TerminalIcon />` 终端图标与动态状态胶囊（`idle` / `exit 0`）。
  - 输出工具组：内置「清空」、「复制结果」、「发送结果」（一键将终端运行输出直接发送到当前聊天会话中！）。
  - 沉浸终端：纯黑 `#09090b` xterm 画布，与左侧编辑器达到高度视觉统一。

## 📝 图片文字提取工坊重构 (OCR Workshop)
- **纯净高对比纯白底色**：浅色模式下采用 **100% 纯白 `#ffffff` 画布**，搭配细腻的 `1.5px solid #e2e8f0` 边框与微弱内阴影，消除原先发灰发污问题。
- **状态徽标化**：顶部的「未选择图片 / 文件名」升级为圆角微徽标，不再是单薄的原生纯文本。
- **深色模式适配**：深色模式下同步适配 `#09090b` 高对比纯黑底色与 `#27272a` 边框。

8. **极简微信 / iOS 原生设计体系全面升级 (WeChat & iOS Native Design Elevation)**：
   - **顶栏去胶囊化与微信化**：彻底移除冗余沉重的连接链条胶囊（`此设备 -> 连接状态 -> 对方设备`），将连接信息收敛至右上角 `···` 详情面板。顶栏升级为微信/iOS 标准单行原生导航栏（高度 52px，左侧大触控区 `‹ 返回`，中间设备名与微型在线绿点，右侧 `···` 更多操作）。
   - **去卡片化与空状态极简化**：移除中央占满屏幕的多层白卡与巨大按钮，替换为微信/Telegram 风格的极简轻柔水印提示（`54px` 柔和头像 + 居中文本 + 极简胶囊按钮），彻底消除臃肿感。
   - **沉浸式消息流与底栏原生化**：
     - 己方气泡：经典微信翡翠绿（`#07c160`），柔和微圆角，文字清晰易读。
     - 对方气泡：纯白卡片底色（暗黑模式下 `#1e1e22`），细微发丝边框。
     - 底部输入栏：浅灰底色（`#f7f7f8` / `#18181b`）+ 纯白圆角输入框（`#ffffff` / `#27272a`）+ 无边框透明 Emoji 按钮 + 极简圆圈发送键。
